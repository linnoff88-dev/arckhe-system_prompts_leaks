## Como usar

1. **Comece pelo glossário** — 5 minutos para ganhar o vocabulário.
2. **Leia 1 ficha por dia** — cada uma tem exemplos reais com caminho de arquivo; abra o arquivo citado e veja o padrão no contexto.
3. **Termine no diff anotado** — é onde os padrões ganham vida: cada mudança real é um padrão sendo aplicado (ou um antipadrão sendo removido).

## A tese em uma frase

> Os melhores system prompts de 2026 não são os mais longos — são os mais **consolidados, justificados e em camadas**. Robustez vem da simplicidade, não apesar dela.
